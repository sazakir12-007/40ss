The 40 Salawat & Salaam upon the Prophet ﷺ, embedded on any page.

== Description ==

Shows the 40 Darood wa Salam with Arabic, transliteration and translation, sources and virtues. Readers can pick a theme and Arabic font, highlight the durood they are reciting, read vertically or sideways, and use timed auto scroll. Settings are remembered in the reader's browser.

== Installation ==

1. Plugins → Add New → Upload Plugin, choose darood-wa-salam.zip and activate it.
2. Add the shortcode to any page or post (in the block editor use the "Shortcode" block):

   [darood_wa_salam]

   Optional height: [darood_wa_salam height="700px"] (px, vh, em or rem; default 85vh).
